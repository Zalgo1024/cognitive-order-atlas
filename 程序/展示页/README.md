# 三权理论 · 展示页

单文件交互式电子书，用于介绍「三权理论」。

## 理论一句话

三权理论是一套关于社会认知秩序如何被生产的分析框架：用「定义权 · 解释权 · 话语权」三个功能位置，
拆解同一件事为什么可以有不同名称、不同意义、不同抵达范围——并说明这三项能力如何分离、组合、转移与反噬。

## 交互原语库

页面不做一次性组件，而是用一套声明式原语组合而成：

| 原语 | 做什么 |
| --- | --- |
| `chain` | 传导链：节点串 + 箭头，三种模式（inspect 查看 / remove 移除看后果 / gate 切换阻断） |
| `stepper` | N 个开关 → 实时输出结论卡（8 种组合状态） |
| `slider` | 连续变量 → 仪表 + 阶段文案 + 阈值触发（discrete / ranges 两种） |
| `picker` | 选项卡 → 内容面板切换 |
| `matrix` | 二维网格，行列交叉呈现内容 |
| `sim` | 多步推演播放器，可自动／单步／重置 |
| `closure` | 定义闭合模拟（标签 × 反应吸收） |
| canvas | 手绘概念地图：中心 + 三维 + 跨维接力弧线，跟随主题换色 |

新增一节只需写正文 + 一段 `data-*` 规格数据，无需改动渲染逻辑。
